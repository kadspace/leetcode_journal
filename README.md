# leetcode_journal

personal leetcode journal for SQL and Python problems.

## structure

```text
leetcode_journal/
  Python/     python problem attempts
  SQL/        sql problem notes
  README.md
```

## workflow

1. do new problems in either `SQL/` or `Python/`.
2. use AI to summarize the GPT convos that helped me solve them.
3. save the useful notes / final solution without random chat noise.
4. re-do the problems.

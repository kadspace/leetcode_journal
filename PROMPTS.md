# LeetCode Journal Prompts

## The "Repo Buddy" Sanitizer
*Paste this at the very end of your chat session to generate a clean, copy-pasteable note for your repo.*

***

**PROMPT:**

> I want to archive this session for my personal engineering journal.
>
> Please **summarize** our entire discussion into a single Markdown block.
>
> **Rules:**
> 1.  **Sanitize**: Remove any personal information, sensitive data, or irrelevant conversational fluff.
> 2.  **Structure**: logic should follow this format:
>     *   **Initial Approach & Struggles**: Briefly describe what I tried first and where I got stuck (be specific about the logic trap).
>     *   **Target Speed & Complexity**: What was the Goal vs Actual? (e.g., O(n) vs O(n^2)).
>     *   **Key Learnings**: Bullet points on new syntax, specific algorithms, or mental models I should remember.
>     *   **Code**: If we arrived at a working solutions, include the final Python code block.
> 3.  **Output Format**: wrapping the ENTIRE result in a single `markdown` code block so I can copy-paste it directly into a file called `notes.md`.
>
> **GO.**

# LeetCode Journal Prompts

## The "Repo Buddy" Sanitizer
*Paste this at the very end of your chat session to generate a clean, copy-pasteable note for your repo.*

***

**PROMPT:**

> I want to archive this session for my personal engineering journal.
>
> Please **summarize** our entire discussion into a single Markdown block.
>
> **Rules:**
> 1.  **Sanitize**: Remove any personal information, sensitive data, or irrelevant conversational fluff.
> 2.  **Voice & Tone**: STRICTLY NO "LLM-speak" (e.g., "In conclusion", "delve", "testament"). Write like a senior engineer: concise, factual, specific. No robotic enthusiasm.
> 3.  **Structure**: logic should follow this format:
>     *   **The Struggle (Mental Sandbox)**: What was my initial thought process? What specifically confused me? Capture the "aha" moment or the logic trap I fell into.
>     *   **Target Speed & Complexity**: Goal vs Actual (e.g., O(n) vs O(n^2)).
>     *   **Key Learnings**: Bullet points on new syntax, specific algorithms, or mental models.
>     *   **Code**: The final working Python code block.
> 4.  **Output Format**: wrapping the ENTIRE result in a single `markdown` code block so I can copy-paste it directly into a file called `notes.md`.
>
> **GO.**

SQL Problem: Rising Temperature

Table: Weather

+-------------+------+
| Column Name | Type |
+-------------+------+
| id          | int  |
| recordDate  | date |
| temperature | int  |
+-------------+------+

id is the primary key for this table.
recordDate contains the date of the weather record.
temperature contains the temperature on that date.

Write a SQL query to find the id of each day where the temperature was higher than the temperature on the previous calendar day.

Return the result table in any order.

Example:

Input:
Weather table

+----+------------+-------------+
| id | recordDate | temperature |
+----+------------+-------------+
| 1  | 2015-01-01 | 10          |
| 2  | 2015-01-02 | 25          |
| 3  | 2015-01-03 | 20          |
| 4  | 2015-01-04 | 30          |
+----+------------+-------------+

Output:

+----+
| id |
+----+
| 2  |
| 4  |
+----+

Explanation:
On 2015-01-02, the temperature was 25, which is higher than 10 on the previous day.
On 2015-01-04, the temperature was 30, which is higher than 20 on the previous day.
